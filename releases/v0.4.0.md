# Autopraxis v0.4.0

Adds an adversarial-probe workflow and tighter scope controls for planning and review.

## Highlights

- `adversarial-probe` offers bounded stress, fault, and agent-safety probing, with approval gates for live or destructive tests.
- `plan-to-launch` starts with the smallest outcome-bearing release; multi-persona PRD/DD councils include `mvp` and `occams-razor` to challenge feature and design bloat before implementation planning.
- Grounding checks existing capabilities before proposing infrastructure. Material scope expansion pauses for human approval, and implementation defaults to at most two issue-wide PRs.
- PR URL reviews publish an idempotent, head-pinned GitHub review unless explicitly requested as read-only; prior feedback is checked to avoid repeating comments. Merge remains human-owned.
